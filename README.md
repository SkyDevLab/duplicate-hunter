# 🕵️ Duplicate Hunter

### *AI-assisted duplicate detection for GitHub Issues and Pull Requests.*

**Duplicate Hunter** is a GitHub App for detecting duplicate GitHub issues and pull requests, explaining matching evidence, and helping open-source maintainers review potential duplicates before closing anything.

## 🌟 Key Highlights

- **Explainable Evidence:** Instead of an opaque number like `Similarity: 93%`, Duplicate Hunter explains the exact evidence (matching exception names, stack trace frames, reproduction steps, component names, and environment differences).
- **False-Positive Protection:** Prefers *"Potentially related"* over *"This is definitely a duplicate"*. Never marks issues as duplicate without explicit maintainer confirmation.
- **Bot Idempotency:** Checks whether Duplicate Hunter already commented, avoids spamming repeated comments, and updates existing reports only when analysis materially changes.
- **Provider-Independent AI:** Works out of the box with zero external network dependencies using built-in deterministic subword feature hashing, and optionally supports OpenAI (`text-embedding-3-small`) or local Ollama instances.
- **Security-First Architecture:** Treats all issue content as untrusted input. Protects against prompt injection attacks, delimiter hijacking, and ReDoS.
- **Modern Maintainer Dashboard:** Next.js + React + Tailwind CSS dashboard providing overview metrics, recent detections, live maintainer review buttons, interactive test simulator, and one-click GDPR data deletion.

## 💬 Example Comment Generated by Duplicate Hunter

When a new issue is opened, Duplicate Hunter posts a structured, developer-focused comment:

```markdown
### 🕵️ Duplicate Hunter

I found **2 potentially related issues**.

#### #1927 — Crash during CSV import

**Confidence: High**

Matching signals:

* ✓ Same CSV import operation
* ✓ Similar crash description
* ✓ Same `NullReferenceException`
* ✓ Similar reproduction steps
* ✓ Same affected component

#### #2144 — Application crashes with large CSV files

**Confidence: Medium**

Matching signals:

* ✓ CSV import
* ✓ Large file handling
* ✓ Application crash

### Difference

The new issue reports Windows 11, while #1927 was reported on Windows 10.

⚠️ **This may be a duplicate. Please review before closing.**

[View #1927](https://github.com/org/repo/issues/1927) [View #2144](https://github.com/org/repo/issues/2144)
```

## 🔄 Detection Modes

1. **Issue → Issue:** Finds potentially duplicate existing open issues.
2. **Issue → PR:** Detects whether an existing pull request already addresses the reported issue (*"💡 This issue may already be addressed by PR #782"*).
3. **PR → PR:** Detects overlapping or duplicate pull requests across contributors.
4. **Issue → Closed Issue:** Identifies solved historical issues and links to the resolving release tag.

## ⚙️ Configuration (`.github/duplicate-hunter.yml`)

Repositories can customize Duplicate Hunter by committing `.github/duplicate-hunter.yml`:

```yaml
enabled: true

issues:
  enabled: true
  threshold: 0.78            # Minimum score to consider an issue related (0.1 - 1.0)
  searchClosedIssues: true    # Compare against solved historical issues
  maxLookbackIssues: 500     # Number of recent issues to evaluate

pullRequests:
  enabled: true
  threshold: 0.80            # Minimum score for PR duplicate matching

maxCandidates: 5             # Maximum candidate matches to report

comment:
  enabled: true
  minConfidence: medium      # Options: high | medium | low
  header: "### 🕵️ Duplicate Hunter"

labels:
  enabled: true
  label: possible-duplicate  # Automatically applied label (never definitive 'duplicate')
  reviewLabel: duplicate-review

checks:
  enabled: true
  failureMode: neutral       # Options: neutral | failure | success

confidenceWeights:
  semantic: 0.35
  error: 0.20
  component: 0.15
  reproduction: 0.10
  environment: 0.08
  version: 0.05
  label: 0.04
  referencedCode: 0.03

ai:
  provider: local            # Options: local | openai | ollama
  # model: text-embedding-3-small

retentionDays: 90
```

## 📊 Maintainer Dashboard

The web dashboard (`apps/web`) provides maintainers with:
- **Overview Metrics:** Issues analyzed, potential duplicates, confirmed duplicates, false positives, issues saved.
- **Recent Detections Table:** Review candidates, inspect signal checklists and differences, and record decisions:
  - `Confirmed Duplicate`
  - `Related`
  - `Not Related`
  - `False Positive`
- **Interactive Simulator:** Test any two issues or stack traces in real time before deployment.
- **Repository Settings Editor:** Adjust thresholds, AI providers, and labels with instant preview.
- **Privacy & Security Controls:** Review data transmission policy and trigger one-click permanent repository data deletion.

## 🚀 Quick Start & Local Development

### Prerequisites
- Node.js 20.x or higher
- npm 10.x or higher

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Test Suite
```bash
npm test
```
Duplicate Hunter includes a complete test suite covering webhook signature validation, prompt injection defense, signal extraction, similarity fixtures, bot idempotency, and maintainer reviews.

### 3. Start Web Dashboard
```bash
npm run dev:web
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Start Standalone GitHub Bot Server
```bash
npm run dev:bot
```
The webhook listener will run at [http://localhost:3001/api/webhook](http://localhost:3001/api/webhook).

## 🔒 Security & Privacy

- **Untrusted Input Sanitization:** All issue descriptions and comments are sanitized to neutralize prompt injection attacks (`IGNORE PREVIOUS INSTRUCTIONS`, `[INST]`, `<|system|>`).
- **Cryptographic Signature Verification:** Webhook payloads are verified with `crypto.timingSafeEqual` and HMAC-SHA256.
- **Zero Third-Party Leaks by Default:** The default `local` provider executes 100% offline with zero external network calls.
- **Data Deletion Mechanism:** Permanent deletion API available at `DELETE /api/repositories/:id/data`.

For full details, see [docs/security.md](docs/security.md) and [docs/privacy.md](docs/privacy.md).
