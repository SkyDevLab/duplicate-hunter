# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Duplicate Hunter, please do **NOT** open a public issue.

Instead, report it securely by contacting the maintainers or filing a GitHub Private Security Advisory via GitHub's Security Advisory tab.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
